本目录包含水文测验学课程的三个编程加分作业示例。


## 作业要求

### 选项1：大断面计算程序
- 程序可运行、结果正确、图表规范
- 实现水位-面积关系计算

### 选项2：平均分割法和中间分割法比较的证明
- 证明方法正确的可获得加分
- 可参考垂线精简比较示例

### 选项3：脉动试验、垂线精简编写程序
- 实现流速脉动数据处理功能
- 实现垂线平均流速计算功能
